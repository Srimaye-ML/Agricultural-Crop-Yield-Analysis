# Agricultural Crop-Yield Analysis

## About
This is my YuvaIntern project for learning how to analyse historical crop-yield data using Python. I plan to check and prepare the data, explore yield patterns, and assess whether it can support a basic machine-learning model.

## Project status
**Week 1 — Strategic planning**

The Week 1 report describes the project challenge, objectives, planned methods, success measures, resources, and risks. Data analysis and model results will be added after I complete that work.

## Dataset
The project uses the `crop_yield.csv` dataset from [Kaggle](https://www.kaggle.com/datasets/akshatgupta7/crop-yield-in-indian-states-dataset). The listing states that it is licensed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).

The dataset file is not included here. Please download it from the source above. I will document any changes made during data preparation.
